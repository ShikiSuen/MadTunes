# MadTunes 使用說明

## 簡介

MadTunes 是一款面向 Audiophile 和音樂製作人的本機音樂播放器，採用經典的 iTunes 11 風格網格佈局，提供精準、無染色的音訊回放體驗。

---

## 系統需求

- **macOS**: 15.0 或更高版本
- **iOS/iPadOS**: 18.0 或更高版本

---

## 支援的音訊格式

MadTunes 支援以下音訊格式的播放：

| 格式 | 副檔名 |
|------|--------|
| MPEG Audio | `.mp3`, `.mp2` |
| AAC / M4A | `.m4a`, `.aac` |
| Apple Lossless | `.m4a` |
| FLAC | `.flac` |
| WAV | `.wav` |
| AIFF | `.aif`, `.aiff` |
| Ogg Vorbis | `.ogg` |
| Opus | `.opus` |
| Core Audio Format | `.caf` |
| Sound Designer II | `.sd2` |
| Dolby Digital | `.ac3` |

> **注意：** MadTunes 僅支援音訊檔案，不支援影片格式。

## 介面佈局

MadTunes 採用三欄式導航佈局：

```
┌─────────────────┬─────────────────────────────────────┐
│                 │                                     │
│   側邊欄         │          專輯網格區域                │
│  (Sidebar)      │        (Album Grid View)            │
│                 │                                     │
│ • All Music     │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
│ • Favorites     │  │專輯 │ │專輯 │ │專輯 │ │專輯 │   │
│ • 播放清單...    │  │封面 │ │封面 │ │封面 │ │封面 │   │
│                 │  └─────┘ └─────┘ └─────┘ └─────┘   │
│                 │       [展開的專輯曲目列表]            │
├─────────────────┤                                     │
│                 └─────────────────────────────────────┘
│  播放控制條                                                │
│  (Player Controls)                                    │
└───────────────────────────────────────────────────────┘
```

### 1. 側邊欄 (Sidebar)

側邊欄位於左側，包含以下部分：

**資料庫 (Library)**
- **All Music**: 顯示媒體櫃中的所有曲目
- **Favorites**: 顯示標記為喜好的曲目（點擊心形圖示加入）

**動態播放清單 (Dynamic Playlists)**
- 基於層級謂詞驅動（Hierarchical-Predicate-Driven）規則自動比對曲目的述詞驅動型播放清單
- 支援複雜的巢狀條件組合
- 可指定資料來源（Data Source）：使用「All Music」或一個/多個「資料夾播放清單」作為篩選範圍
- 右鍵點擊可重新命名、複製或刪除；使用「+」按鈕新增
- 在 iPhone WPUI 版面中，可點擊齒輪按鈕開啟專用述詞編輯器

**播放清單 (Playlists)**
- 使用者建立的靜態播放清單
- 右鍵點擊可新增、重新命名、複製或刪除播放清單

**資料夾播放清單 (Folder Playlists)**
- 基於指定資料夾掃描音訊檔案的播放清單
- 資料夾播放清單的曲目與主資料庫（All Music）隔離
- 支援自動檢測資料夾變更（Lazy Reload），首次切換時自動更新
- 右鍵點擊可重新掃描資料夾、在 Finder 中開啟（macOS）或刪除播放清單
- 使用側邊欄的「+」按鈕選擇資料夾以建立資料夾播放清單

### 2. 專輯網格區域 (Album Grid)

右上角工具列有個按鈕，可在標準網格佈局與列表式表格視圖之間切換。
專輯網格是主要瀏覽區域：

- **網格佈局**: 自適應欄數，最少 160px 寬度每張專輯
- **專輯卡片**: 顯示專輯封面、專輯名稱、藝人名稱
- **展開/摺疊**: 單擊專輯展開曲目列表；再次單擊或按 Esc 摺疊
- **空白區域點擊收起**: 當專輯展開時，點擊網格中的專輯卡片或詳細視窗外的任何空白處，也會自動摺疊該專輯
- **多選**: 支援 Shift 和 Command 鍵多選專輯

**展開的專輯視圖** (Expanded Album View)

展開後顯示：
- 左側：多欄曲目列表（最多 7 行每欄）
- 右側：大尺寸專輯封面（200×200px）
  - **雙擊封面**：播放該專輯
  - **右鍵封面**：顯示專輯上下文選單
- 曲目資訊：音軌編號、曲名、藝人、時長

### 3. 播放控制條 (Player Controls)

位於視窗底部，包含：

| 元素 | 功能 |
|------|------|
| 專輯封面縮圖 | 雙擊跳轉到目前播放專輯；右鍵顯示曲目操作選單 |
| 曲名/藝人 | 顯示目前播放資訊 |
| 播放/暫停 | 切換播放狀態 |
| 上一首/下一首 | 切換曲目 |
| 進度條 | 拖動跳轉；點擊時間切換剩餘時間顯示 |
| 音量滑桿 | 調節音量（圖示隨音量變化）|
| 循環模式 | 順序 / 單曲循環 / 亂序 |
| 播放佇列 | 彈出播放佇列面板 |
| 直欄瀏覽器 | 彈出 Genre/Artist/Album 篩選面板 |

**音訊輸出裝置選擇（macOS 獨占）**
- 點擊音量圖示或從 Control 選單，可選擇音訊輸出裝置
- 支援選擇系統預設或特定音訊介面（如外接 DAC、BlackHole 等）
- 目前選取的裝置會在選單中以勾選標記顯示

## 上下文選單功能

### 專輯右鍵選單

- **加入到播放清單**: 將專輯加入指定播放清單
- **播放該專輯（順序）**: 按曲目編號順序播放
- **播放該專輯（亂序）**: 隨機順序播放
- **插播**: 將專輯插入目前播放位置之後立即播放
- **取得資訊**: 檢視專輯中曲目的詳細資訊
- **加入喜好項目**: 將專輯所有曲目標記為喜好
- **顯示於檔案總管**: 在 Finder 中開啟專輯所在檔案夾
- **從資料庫刪除登記**: 從媒體櫃中移除（不刪除原始檔案）

### 曲目右鍵選單

- **加入到播放清單**: 將曲目加入指定播放清單
- **插播**: 將曲目插入目前播放位置之後立即播放
- **取得資訊**: 檢視曲目的詳細中繼資料
- **加入喜好項目**: 將曲目标記为喜好
- **拷貝中繼資料**: 複製 TSV 格式的中繼資料到剪貼簿
- **顯示於檔案總管**: 在 Finder 中開啟曲目所在檔案夾
- **從資料庫刪除登記**: 從媒體櫃中移除（不刪除原始檔案）

## 表格檢視

啟用表格檢視時，媒體櫃會以曲目列表的形式顯示。
列包含名稱、長度、藝人、專輯名稱、專輯藝人、風格
以及資料夾（父資料夾名稱－滑鼠懸停可顯示完整路徑）。

### 表格檢視鍵盤快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `↑` `↓` | 上下移動選擇 |
| `Shift + ↑` `Shift + ↓` | 範圍選擇 |
| `Page Up` / `Page Down` | 上下翻頁 |
| `Shift + Page Up/Down` | 範圍選擇至上一頁/下一頁 |
| `Home` / `End` | 跳至首個/末個曲目 |
| `Shift + Home/End` | 範圍選取至首個/末個曲目 |
| `Return` / `Enter` | 從所選位置播放（同雙擊） |
| `Shift + Space` | 從所選位置播放（同雙擊） |
| `Space` | 播放/暫停 |
| `⌘ + ↓` | 從所選位置播放（同雙擊） |
| `⌘ + A` | 全選可見曲目 |
| `⌘ + C` | 將所選曲目的中繼資料（TSV 格式）拷貝至剪貼簿 |
| `⌥ + ↑` | 在播放清單中上移所選曲目（僅限喜好項目 / 靜態播放清單）|
| `⌥ + ↓` | 在播放清單中下移所選曲目（僅限喜好項目 / 靜態播放清單）|

### 欄位自訂與排序

- **欄位顯示**: 右鍵點擊表頭可透過開關選單來顯示或隱藏欄位。
- **調整欄寬**: 拖曳欄位標頭之間的分隔線可調整欄寬，寬度設定會跨工作階段保留。
- **排序**: 點擊欄位標題可依該欄位排序（點擊一次升序 ▲、再次點擊降序 ▼、第三次點擊清除排序恢復專輯順序）
- **範性排序**（僅「所有音樂」）：點擊其他欄位標題可新增次要/第三排序條件。每個標題會顯示下標數字表示優先序（如 ▲₁ ▼₂）。
- **持久排序**（喜好項目與靜態播放清單）：點擊欄位標題會永久重新排列播放清單中的曲目。再次點擊同一欄位可切換升序/降序。重新排序後的順序會自動儲存。

### 播放清單曲目重排序

在喜好項目和使用者建立的靜態播放清單中（當表格未排序、未搜尋、未啟用直欄篩選時），可以重新排列曲目：

- **拖曳排序**: 拖動曲目（或多選的曲目）到另一列以重新排序。
- **鍵盤排序**: 選取曲目後按 `⌥ + ↑` / `⌥ + ↓` 上下移動。

> **注意**：當 Column Browser 篩選規則啟用或搜尋框有內容時，靜態播放清單的排序調整功能會被自動禁用。

## 搜尋與篩選

### 關鍵字搜尋

右上角搜尋框支援以下過濾模式：

| 模式 | 說明 |
|------|------|
| 任一 | 搜尋曲目名稱、專輯名稱、藝人 |
| 曲目名稱 | 僅搜尋曲目名稱 |
| 專輯名稱 | 僅搜尋專輯名稱 |
| 藝人 | 僅搜尋藝人名稱 |

### 直欄瀏覽器 (Column Browser)

透過播放控制條的篩選按鈕開啟：

- **四欄篩選**: Genre → Album Artist → Song Artist → Album
- **雙向互限**：挑選歌曲藝人時也會限制專輯藝人的列表。
- **級聯過濾**: 選擇 Genre 後會過濾可用的 Artist 列表
- **多選**: 每欄支援選擇多個項目
- **雙擊播放**: 在任意欄中雙擊可播放符合條件的曲目

## 動態播放清單（Dynamic Playlist）

動態播放清單是基於規則自動篩選曲目的強大功能：

### 述語編輯器（Predicate Editor）

- 支援建立複雜的**層級謂詞網路（Hierarchical Predicate Network）**，可巢狀組合多個條件群組
- 卡片式圓角矩形層級佈局，視覺化呈現條件之間的邏輯關係
- 即時預覽符合條件的曲目數量
- 支援以下條件欄位：名稱、藝人、專輯、專輯藝人、曲號、風格、年份、長度、副檔名、資料夾

### 資料來源（Data Source）

- 可指定動態播放清單的資料來源範圍：
  - **All Music**（預設）：從整個音樂資料庫篩選
  - **指定資料夾播放清單**：從一個或多個資料夾播放清單中篩選曲目
- 在播放清單右鍵選單或述語編輯器中可調整資料來源
- 綁定資料來源後，動態播放清單圖示會變為 `folder.fill.badge.gearshape`

---

## 資料夾播放清單（Folder Playlist）

資料夾播放清單讓您直接播放指定資料夾中的音訊檔案，無需將其匯入主資料庫：

### 特性

- **獨立隔離**：曲目與主資料庫（All Music）完全隔離，保持主資料庫整潔
- **自動掃描**：首次建立時自動掃描資料夾中的所有支援格式音訊檔案
- **Lazy Reload**：App 啟動後首次切換到資料夾播放清單時，自動檢測資料夾變更並更新內容
- **手動重新掃描**：右鍵點擊播放清單可手動觸發重新掃描

### 使用方式

1. 點擊側邊欄底部的「+」按鈕，選擇「新增資料夾播放清單」
2. 選擇要監控的資料夾
3. 播放清單會自動建立並掃描該資料夾及其子資料夾中的所有音訊檔案

### 注意事項

- 資料夾播放清單**不支援**複製功能
- 曲目無法直接從資料夾播放清單「刪除」（因為檔案由外部資料夾管理）
- 可將資料夾播放清單的曲目匯入至主資料庫，或作為動態播放清單的資料來源

## 播放佇列管理

### 佇列操作

播放佇列面板中可執行：

- **拖曳排序**: 拖動曲目調整播放順序
- **移除曲目**: 點擊 × 按鈕或按 Delete 鍵
- **隨機打亂**: 點擊頂部亂序按鈕
- **上下移動**: 使用箭頭按鈕微調位置

### 循環模式

| 模式 | 圖示 | 說明 |
|------|------|------|
| 順序播放 | ⟳ | 按順序播放，結束後停止 |
| 單曲循環 | ⟳1 | 重複播放目前曲目（首尾無縫銜接）|
| 亂序播放 | ⇄ | 隨機順序播放佇列中的曲目 |

## 匯入音樂

### 匯入方式

1. **檔案匯入**: 支援選擇多個音訊檔案
2. **檔案夾匯入**: 遞迴掃描檔案夾中的所有音訊檔案
3. **拖曳匯入**: 將檔案或檔案夾拖入 MadTunes 視窗
4. **「以此 App 開啟」/ 分享**: 透過 Finder、「檔案」App 或其他應用程式的「以此 App 開啟」或分享選單將音訊檔案傳送給 MadTunes

### 匯入特性

- **並行處理**: 最多 8 個檔案同時讀取中繼資料
- **重複偵測**: 自動跳過已匯入的相同檔案
- **中繼資料讀取**: 自動讀取 ID3 標籤和專輯封面
- **安全範圍書籤**: macOS 下使用安全書籤維持檔案存取權限
- **播放清單同步**: 若在「Favorites」頁面或任意自訂靜態播放清單頁面執行匯入，匯入完成後這些曲目也會自動加入該播放清單（重複項會被跳過）
- **動態播放清單保護**: 拖放檔案至動態播放清單時不會自動加入曲目（動態播放清單的內容完全由述詞驅動）

## 音訊特性

### 高品質回放

MadTunes 針對 macOS 音訊系統進行了專門最佳化：

- **系統級 AVPlayer 核心**: 經過上百次實測驗證，macOS 平台唯有使用系統原生 AVPlayer 才能確保最佳音質表現。測試專輯涵蓋加藤達也《食戟之靈 OST》、梁靜茹《勇氣》《可惜不是你》、FLOW《Go!!!》《Sign》、ずっと真夜中でいいのに《勘ぐれい》、方順吉（張翊華混音作品）、√5《千本桜》、周杰倫《軌跡》等，確認各類型音樂的細節都能精準呈現
- **HAL 緩衝區調整**: 自動增大輸出裝置緩衝區，防止音訊抖動
- **精確立體聲**: 無 HRTF 處理，忠實還原原始混音
- **無縫循環**: 單曲循環模式下，曲目首尾銜接無停頓

### 中繼資料顯示

在「取得資訊」視窗中可檢視：

- 基礎資訊：曲名、藝人、專輯、年份、類型
- 技術資訊：取樣率、位元深度、聲道數、編碼格式
- 檔案資訊：檔案路徑、檔案大小、修改日期

## 資料管理

### 媒體櫃儲存

MadTunes 使用 SwiftData 持久化儲存：

- 曲目中繼資料（非原始音訊檔案）
- 播放清單
- 喜好標記
- 檔案安全書籤（macOS）

### 注意事項

- 從媒體櫃刪除曲目**不會**刪除原始音訊檔案
- 專輯封面自動壓縮快取（最大 512×512，JPEG 格式）
- 重新匯入已存在的檔案會更新其中繼資料

## 互動風格總結

MadTunes 的互動設計遵循以下原則：

1. **直接操作**: 雙擊播放、拖曳排序、即時反饋
2. **鍵盤優先**: 全面的鍵盤導航支援，無需滑鼠即可完成大部分操作
3. **漸進展開**: 網格 → 專輯 → 曲目，資訊層級清晰
4. **無損編輯**: 所有刪除操作僅影響媒體櫃索引，原始檔案安全
5. **macOS 原生**: 遵循 Apple Human Interface Guidelines，支援系統特性如 Spotlight、Force Touch 等

## 故障排除

### 常見問題

| 問題 | 解決方案 |
|------|----------|
| 無法播放檔案 | 檢查檔案是否在原位置；嘗試重新匯入 |
| 匯入速度慢 | 大量檔案時屬於正常現象；支援背景匯入 |
| 專輯封面不顯示 | 檢查音訊檔案是否內嵌封面；支援 FLAC/MP3/M4A 封面讀取 |
| 播放時有卡頓 | 檢查系統音訊設定；關閉其他占用音訊的應用 |
