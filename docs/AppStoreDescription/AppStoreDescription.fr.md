# MadTunes - Description Mac App Store

## Nom de l'App

MadTunes

## Sous-titre (30 caractères max)

Lecteur Musical Audiophile

## Description

MadTunes est un lecteur musical local conçu pour les audiophiles et les producteurs de musique, offrant une lecture audio haute fidélité précise et pure.

**Pourquoi MadTunes ?**

En tant que créateur de musique, vous avez besoin d'outils de lecture qui révèlent avec précision les détails du mixage. Validé à travers plus de 100 tests rigoureux, seul l'AVPlayer natif du système (du framework AVFoundation) garantit une qualité audio optimale sur macOS / iOS. MadTunes s'appuie sur cette base, présentant fidèlement l'audio original sans traitement sonore supplémentaire, vous permettant d'entendre le son authentique de qualité studio.

**Fonctionnalités Clés :**

• **Support de Formats Étendu** — MP3, FLAC, AAC, WAV, AIFF, Ogg Vorbis, Opus et d'autres formats audio courants (fichiers audio uniquement) ;
• **Lecture en Boucle sans Rupture de Rythme** — Conçu pour l'audio en boucle, transition rythmiquement cohérente aux points de boucle ;
• **Stéréo Précise** — Reproduit fidèlement le mixage original, sans interférence HRTF ;
• **Navigation Clavier Puissante** — Support complet du clavier sur iPad / macOS, de la navigation en grille à la gestion de file d'attente sans souris ;
• **Recherche & Filtre Intelligents** — Recherche par mot-clé + filtre en cascade à trois colonnes (Genre/Artiste/Album) ;
• **File d'Attente de Lecture Flexible** — Glisser-déposer pour réorganiser, lire ensuite, aléatoire, contrôle complet de la lecture ;
• **Gestion de Playlists** — Créez des playlists personnelles pour organiser votre collection musicale.
• **Optimisé pour les Appareils Apple** — validé à travers plus de 100 tests pour garantir la meilleure qualité audio sur macOS / iOS ;

MadTunes ne collecte aucune donnée utilisateur. Tous les fichiers musicaux sont traités localement — votre vie privée est entièrement protégée.

**Formats Supportés :** MP3, FLAC, AAC, M4A, WAV, AIFF, Ogg Vorbis, Opus, CAF
