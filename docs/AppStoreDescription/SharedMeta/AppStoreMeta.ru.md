# Метаданные App Store - MadTunes (Русский)

## Название Приложения

MadTunes

## Подзаголовок (макс. 30 символов)

Плеер для Истинных Аудиофилов

## Промо-текст (макс. 170 символов)

Музыкальный плеер для аудиофилов с классической сеточной навигацией и точным воспроизведением. Поддерживает FLAC/MP3/AAC с бесшовным воспроизведением по кругу, динамические и папочные плейлисты.

## Ключевые Слова (макс. 100 символов)

Музыкальный плеер, Аудиофил, FLAC, Без потерь, Локальная музыка, MP3
