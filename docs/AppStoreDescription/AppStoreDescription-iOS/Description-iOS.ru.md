# Описание в App Store - MadTunes iOS (Русский)

MadTunes — это локальный музыкальный плеер, разработанный для аудиофилов и музыкальных продюсеров, обеспечивающий точное и чистое высококачественное воспроизведение аудио.

**Почему MadTunes?**

Как создатель музыки, вам нужны инструменты воспроизведения, которые точно раскрывают детали микширования. Проверенный более чем 100 строгими тестами, только системный нативный AVPlayer (из фреймворка AVFoundation) гарантирует оптимальное качество звука на iOS. MadTunes построен на этой основе, точно передавая оригинальное аудио без дополнительной обработки звука, позволяя вам услышать настоящий студийный звук.

**Ключевые Функции:**

• **Широкая Поддержка Форматов** — MP3, FLAC, AAC, WAV, AIFF, Ogg Vorbis, Opus и другие популярные аудиоформаты (только аудиофайлы);
• **Воспроизведение по Кругу без Разрыва Ритма** — Разработано для зацикливаемого аудио, ритмически согласованный переход в точках зацикливания;
• **Точное Стерео** — Точно воспроизводит оригинальное микширование, без HRTF-интерференции;
• **Мощная Навигация с Клавиатуры** — Полная поддержка клавиатуры на iPad, от навигации по сетке до управления очередью без мыши;
• **Умный Поиск и Фильтр** — Поиск по ключевым словам + четырёхколоночный каскадный фильтр (Жанр/Исполнитель Альбома/Исполнитель Песни/Альбом);
• **Гибкая Очередь Воспроизведения** — Перетаскивание для изменения порядка, воспроизведение следующим, перемешивание, полный контроль воспроизведения;
• **Управление Плейлистами** — Поддержка статических плейлистов, динамических плейлистов Hierarchical-Predicate-Driven и папочных плейлистов (воспроизведение аудиофайлов напрямую из указанных папок);
• **Источник Данных Динамического Плейлиста** — Настройка источника данных динамических плейлистов как "All Music" или конкретных папочных плейлистов;
• **Оптимизировано для Устройств Apple** — проверено более чем 100 тестами для обеспечения лучшего качества звука на iOS;

MadTunes не собирает пользовательские данные. Все музыкальные файлы обрабатываются локально — ваша конфиденциальность полностью защищена.

**Поддерживаемые Форматы:** MP3, FLAC, AAC, M4A, WAV, AIFF, Ogg Vorbis, Opus, CAF
