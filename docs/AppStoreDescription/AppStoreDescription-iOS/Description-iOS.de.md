# App Store Beschreibung - MadTunes iOS (Deutsch)

MadTunes ist ein lokaler Musikplayer, der für Audiophile und Musikproduzenten entwickelt wurde und präzise, reine High-Fidelity-Audiowiedergabe bietet.

**Warum MadTunes?**

Als Musikschöpfer benötigen Sie Wiedergabewerkzeuge, die Mischdetails genau aufdecken. Über 100 rigorose Tests haben bestätigt, dass nur der systemeigene AVPlayer (aus dem AVFoundation Framework) eine optimale Audioqualität auf iOS gewährleistet. MadTunes baut auf dieser Grundlage auf und präsentiert das Original-Audio ohne zusätzliche Klangverarbeitung getreu, sodass Sie den wahren Studio-Sound hören können.

**Hauptfunktionen:**

• **Breite Formatunterstützung** — MP3, FLAC, AAC, WAV, AIFF, Ogg Vorbis, Opus und weitere gängige Audioformate (nur Audiodateien);
• **Rhythmus-kontinuierliche Loop-Wiedergabe** — Für loopbare Audio konzipiert, rhythmuskonsistente Übergänge an Loop-Punkten;
• **Präzises Stereo** — Reproduziert das Original-Mixing getreu, keine HRTF-Interferenz;
• **Leistungsstarke Tastaturnavigation** — Vollständige Tastaturunterstützung auf iPad, von Raster-Navigation bis Warteschlangenverwaltung ohne Maus;
• **Intelligente Suche & Filter** — Keyword-Suche + vierstufige Kaskadenfilter (Genre/Album-Künstler/Song-Künstler/Album);
• **Flexible Wiedergabeliste** — Ziehen zum Neuanordnen, als Nächstes abspielen, Zufallswiedergabe, vollständige Wiedergabesteuerung;
• **Playlist-Verwaltung** — Unterstützung für statische Playlists, Hierarchical-Predicate-Driven Dynamic Playlists und Ordner-Playlists (Audio-Dateien direkt aus angegebenen Ordnern abspielen);
• **Dynamische Playlist-Datenquelle** — Konfigurieren Sie die Datenquelle dynamischer Playlists als "All Music" oder spezifische Ordner-Playlists;
• **Für Apple-Geräte optimiert** — über 100 Tests validiert, um beste Audioqualität auf iOS zu gewährleisten;

MadTunes sammelt keine Benutzerdaten. Alle Musikdateien werden lokal verarbeitet — Ihre Privatsphäre ist vollständig geschützt.

**Unterstützte Formate:** MP3, FLAC, AAC, M4A, WAV, AIFF, Ogg Vorbis, Opus, CAF
