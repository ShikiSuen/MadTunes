# App Store 説明文 - MadTunes iOS（日本語）

MadTunes は、オーディオマニアと音楽制作者向けに設計されたローカル音楽プレーヤーです。正確で純粋な高忠実度オーディオ再生を提供します。

**なぜ MadTunes を選ぶのか？**

音楽制作者として、ミックスのディテールを正確に引き出す再生ツールが必要です。100回以上の厳密なテストを経て検証済み、iOS プラットフォームではシステムネイティブの AVPlayer を使用することのみが最高の音質を保証します。この基盤の上に構築された MadTunes は、追加のサウンド処理なしで元のオーディオを忠実に再現し、スタジオ品質の本物のサウンドを聴くことができます。

**主な機能：**

• **幅広いフォーマットサポート** — MP3、FLAC、AAC、WAV、AIFF、Ogg Vorbis、Opus などの主流オーディオフォーマットに対応（音響ファイルのみ）；
• **リズム一致のループ再生** — ループ可能なオーディオ向けに設計、ループポイントでリズム一致的な移行；
• **正確なステレオ** — 元のミックスを忠実に再現、HRTF の干渉なし；
• **強力なキーボードナビゲーション** — iPad でのフルキーボードサポート、グリッドナビゲーションからキュー管理までマウス不要；
• **スマート検索＆フィルター** — キーワード検索 + 4カラムカスケードフィルター（ジャンル/アルバムアーティスト/曲アーティスト/アルバム）；
• **柔軟な再生キュー** — ドラッグで並べ替え、次に再生、シャッフル、完全な再生コントロール；
• **プレイリスト管理** — 静的プレイリスト、階層述語駆動ダイナミックプレイリスト、フォルダプレイリスト（指定フォルダの音声ファイルを直接再生）をサポート；
• **ダイナミックプレイリストのデータソース** — ダイナミックプレイリストのデータソースを「All Music」または特定のフォルダプレイリストに設定可能；
• **Apple デバイス向けに最適化** —— システム内蔵の Apple AVPlayer コアを利用 — 100回以上のテストを経て iOS プラットフォームでの最高音質を保証。

MadTunes はユーザーデータを収集しません。すべての音楽ファイルはローカルで処理され、プライバシーは完全に保護されます。

**対応フォーマット：** MP3, FLAC, AAC, M4A, WAV, AIFF, Ogg Vorbis, Opus, CAF
