# App Store 簡介 - MadTunes iOS（繁體中文）

MadTunes 是一款專為音樂發燒友和音樂製作人設計的本機端音樂播放器，為您帶來精準、純淨的高品質音訊播放體驗。

**為什麼選擇 MadTunes？**

身為音樂創作者，您需要能準確還原混音細節的播放工具。經過上百次實測驗證，在 iOS 平台上唯有使用系統原生 AVPlayer 才能確保最佳的音質表現。MadTunes 即以此為核心，忠實重現原始音訊，絕無額外的音效處理，讓您聽見錄音室等級的真實聲音。

**核心特性：**

• **廣泛格式支援** —— 將 MP3、FLAC、AAC、WAV、AIFF、Ogg Vorbis、Opus 等主流音訊格式一網打盡（僅支援音訊檔案）；
• **循環播放時節奏一致** —— 專為可循環音訊設計，單曲循環播放時首尾無縫銜接，確保節奏一致；
• **精準立體聲** —— 忠實還原原始混音，無 HRTF 處理干擾；
• **強大鍵盤導覽** —— iPad 全程支援鍵盤操作，從格狀檢視導覽到佇列管理，完全無需使用滑鼠；
• **智慧搜尋篩選** —— 關鍵字搜尋 + 四欄位連動篩選（類型／專輯藝人／歌曲藝人／專輯）；
• **靈活播放佇列** —— 拖曳排序、插播、隨機播放，完全掌控播放流程；
• **播放清單管理** —— 支援靜態播放清單、層級謂詞驅動動態播放清單與資料夾播放清單（直接播放指定資料夾內容）；
• **動態播放清單資料來源** —— 可指定動態播放清單的資料來源為「All Music」或特定資料夾播放清單；
• **為 Apple 裝置最佳化** —— 採用系統內建的原生 Apple AVPlayer 核心，經過上百次實測驗證，確保 iOS 平台上的最佳音質表現。

MadTunes 不收集任何使用者資料，所有音樂檔案皆於本機端處理，充分保障您的隱私權。

**支援格式：** MP3, FLAC, AAC, M4A, WAV, AIFF, Ogg Vorbis, Opus, CAF
