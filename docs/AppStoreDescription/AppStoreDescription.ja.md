# MadTunes - Mac App Store 説明文

## アプリ名

MadTunes

## サブタイトル（30文字以内）

オーディオマニア向け音楽プレーヤー

## 説明（メイン）

MadTunes は、オーディオマニアと音楽制作者向けに設計されたローカル音楽プレーヤーです。正確で純粋な高忠実度オーディオ再生を提供します。

**なぜ MadTunes を選ぶのか？**

音楽制作者として、ミックスのディテールを正確に引き出す再生ツールが必要です。100回以上の厳密なテストを経て検証済み、macOS / iOS プラットフォームではシステムネイティブの AVPlayer を使用することのみが最高の音質を保証します。この基盤の上に構築された MadTunes は、追加のサウンド処理なしで元のオーディオを忠実に再現し、スタジオ品質の本物のサウンドを聴くことができます。

**主な機能：**

• **幅広いフォーマットサポート** — MP3、FLAC、AAC、WAV、AIFF、Ogg Vorbis、Opus などの主流オーディオフォーマットに対応（音響ファイルのみ）；
• **リズム一致のループ再生** — ループ可能なオーディオ向けに設計、ループポイントでリズム一致的な移行；
• **正確なステレオ** — 元のミックスを忠実に再現、HRTF の干渉なし；
• **強力なキーボードナビゲーション** — iPad / macOS でのフルキーボードサポート、グリッドナビゲーションからキュー管理までマウス不要；
• **スマート検索＆フィルター** — キーワード検索 + 3カラムカスケードフィルター（ジャンル/アーティスト/アルバム）；
• **柔軟な再生キュー** — ドラッグで並べ替え、次に再生、シャッフル、完全な再生コントロール；
• **プレイリスト管理** — 個人プレイリストを作成し、音楽コレクションを整理。
• **Apple デバイス向けに最適化** —— システム内蔵の Apple AVPlayer コアを利用 — 100回以上のテストを経て macOS / iOS プラットフォームでの最高音質を保証。

MadTunes はユーザーデータを収集しません。すべての音楽ファイルはローカルで処理され、プライバシーは完全に保護されます。

**対応フォーマット：** MP3, FLAC, AAC, M4A, WAV, AIFF, Ogg Vorbis, Opus, CAF
