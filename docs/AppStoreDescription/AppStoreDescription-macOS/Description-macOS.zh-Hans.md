# App Store 简介 - MadTunes macOS（简体中文）

MadTunes 是一款专为音乐发烧友和音乐制作人设计的本地音乐播放器，带来精准、纯净的高品质音频回放。

**为什么选择 MadTunes？**

作为音乐创作者，你需要准确还原混音细节的播放工具。经过上百次实测验证，macOS 平台唯有使用系统原生 AVPlayer 才能确保最佳音质表现。MadTunes 以此为核心，忠实呈现原始音频，无额外音效处理，让你听到录音室级别的真实声音。

**核心特性：**

• **广泛格式支持** —— MP3、FLAC、AAC、WAV、AIFF、Ogg Vorbis、Opus 等主流音频格式一网打尽（仅支持音频文件）；
• **循环播放时节奏一致** —— 专为可循环音频设计，单曲循环时首尾衔接时节奏一致；
• **精准立体声** —— 忠实还原原始混音，无 HRTF 处理干扰；
• **强大键盘导航** —— macOS 全程支持键盘操作，从网格导航到队列管理无需鼠标；
• **智能搜索筛选** —— 关键字搜索 + 四栏级联筛选（风格/专辑艺人/歌曲艺人/专辑）；
• **灵活播放队列** —— 拖拽排序、插播、乱序，完全掌控播放流程；
• **播放清单管理** —— 支持静态播放清单、层级谓词驱动动态播放清单与文件夹播放清单（直接播放指定文件夹内容）；
• **动态播放清单数据来源** —— 可指定动态播放清单的数据来源为「All Music」或特定文件夹播放清单；
• **音频输出设备选择** —— 可将音频输出至指定的音频接口，满足发烧友需求；支持虚拟音频驱动程序，可与 Apple MainStage 整合；
• **为 Apple 设备最佳化** —— 利用系统内建原生 Apple AVPlayer 核心 —— 经过上百次实测验证，确保 macOS 平台最佳音质表现。

MadTunes 不收集任何用户数据，所有音乐文件本地处理，你的隐私完全受保护。

**支持格式：** MP3, FLAC, AAC, M4A, WAV, AIFF, Ogg Vorbis, Opus, CAF
