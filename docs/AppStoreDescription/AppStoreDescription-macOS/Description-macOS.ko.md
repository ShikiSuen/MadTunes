# App Store 설명 - MadTunes macOS（한국어）

MadTunes는 오디오파일과 음악 제작자를 위해 설계된 로컬 음악 플레이어로, 정확하고 순수한 고품질 오디오 재생을 제공합니다.

**왜 MadTunes인가?**

음악 제작자로서 믹싱 디테일을 정확하게 드러내는 재생 도구가 필요합니다. 100번 이상의 엄격한 테스트를 통해 검증된 결과, macOS 플랫폼에서 시스템 네이티브 AVPlayer(AVFoundation 프레임워크)만이 최상의 음질을 보장합니다. MadTunes는 이 기반 위에 구축되어 추가적인 사운드 처리 없이 원본 오디오를 충실히 재현하여 스튜디오급 진정한 사운드를 들을 수 있게 합니다.

**주요 기능:**

• **광범위한 포맷 지원** — MP3, FLAC, AAC, WAV, AIFF, Ogg Vorbis, Opus 등 주류 오디오 포맷 지원(오디오 파일만);
• **리듬 일치 루프 재생** — 루프 가능한 오디오를 위해 설계, 루프 포인트에서 리듬 일관된 전환;
• **정확한 스테레오** — 원본 믹싱을 충실히 재현, HRTF 간섭 없음;
• **강력한 키보드 낵게이션** — macOS에서 풀 키보드 지원, 그리드 낵게이션부터 큐 관리까지 마우스 불필요;
• **스마트 검색 및 필터** — 키워드 검색 + 4열 캐스케이드 필터(장르/앨범 아티스트/곡 아티스트/앨범);
• **유연한 재생 큐** — 드래그로 순서 변경, 다음 재생, 셔플, 완전한 재생 제어;
• **플레이리스트 관리** — 정적 플레이리스트, Hierarchical-Predicate-Driven 동적 플레이리스트, 폴터 플레이리스트(지정된 폴터의 오디오 파일 직접 재생) 지원;
• **동적 플레이리스트 데이터 소스** — 동적 플레이리스트의 데이터 소스를 "All Music" 또는 특정 폴터 플레이리스트로 설정 가능;
• **오디오 출력 장치 선택** — 오디오를 특정 오디오 인터페이스로 라우팅 가능; Apple MainStage와 통합하기 위한 가상 오디오 드라이버 지원;
• **Apple 기기에 최적화** — 100번 이상의 테스트를 통해 macOS 플랫폼에서 최상의 음질 보장;

MadTunes는 사용자 데이터를 수집하지 않습니다. 모든 음악 파일은 로컬에서 처리되며, 귀하의 개인정보는 완전히 보호됩니다.

**지원 포맷:** MP3, FLAC, AAC, M4A, WAV, AIFF, Ogg Vorbis, Opus, CAF
