MadTunes 是一款针对「硬盘上有成千上万的 FLAC / MP3 / M4A 收藏」的发烧用户们（Audiophiles）打造的 HiFi 音乐播放软件。亮点如下：

# 简单且保真

MadTunes 本身不支持 DSP 处理，只是允许你在 macOS 系统下指定音频输出设备。用户可以将音频输出指定到 Soundflower / Blackhole 这种虚拟音频驳接驱动上、借此将音频信号传送给 Apple MainStage 或诸如 GarageBand / Logic Pro / Cubase / Fender Studio Pro 等 DAW 内。这样一来，用户可以让那些 **真正服务于音频工业的** VST / AU 音效 DSP 插件服务于自己的 HiFi 聆听需求。

MadTunes 在 macOS 系统下的音频播放业务的实作简单纯粹：万事交给 macOS / iOS 内建的 AVFoundation 框架内的 AVPlayer 模组。该模组内建 Apple 自研的尖端 SRC 算法。在不追加额外的管线处理的情况下，AVPlayer 的播放声音品质在「声音距离感」「声像清晰度」「细节颗粒度」「呼吸感」等方面非常卓越：只要多一道管线，哪怕这个管线什么也不做，就有可能引入失真。

MadTunes 就是用这种方式让对声音处理品质有追求的用户们更庆幸自己选择了 Mac。一款经典了几十年的 SONY MDR-7506 有线监听耳机，搭配 Mac mini M4 主机，不需要额外的硬件，就能享受如此高品质的立体声音乐播放。

# 音乐数据不必入库

虽然 MadTunes 一开始设计时仍旧使用了「先导入音乐再播放」的思想，但 MadTunes 只导入「文件位置及其沙箱书签」资讯（Mac App Store 的软件必须得开沙箱）以及中继资料（包括专辑封面缓存）。这意味着你不用非得把你的音乐文件收藏强行集中到某个指定的 Library Bundle 内。你想把音乐文件放在哪个硬盘卷宗都可以。如果沙箱书签失效的话，重新导入一遍就能恢复。

然而，奇迹不只于此：自 MadTunes v26.04.01 版开始，用户还可以将整个文件夹作为一种播放清单的形式来使用。动态播放清单也可以将自身的数据源头指定为一个或多个动态播放清单。加上动态播放清单自身的「基于层级谓词（Hierarchical Predicates）来决定内容」的特性，便于将用户想要的那部分内容迅速陈列给用户。如果有曲子要修改 ID3 / Vorbis Comments 中继资料的话，可以在修改完毕之后将文件重新导入。只要文件在硬盘的路径没有变化，那么就可以在重新导入时更新既有曲目的已经缓存了的中继资料。

# 简易的 UI

桌面端的 MadTunes 使用了此前「已经被 Apple 弃用、却很好用很直观」的摺叠式专辑介面交互设计，且在此基础上完善了键盘热键操作体系；iOS 端则启用了 2012 年代最潮流的 Pivot-Pages 风格的 UI 设计，减少使用者在操作时的困惑感。诸如「直栏筛选器」等功能也对手机端的操作习惯做了优化。这两套介面布局在 iPadOS 系统下可以随系统视窗宽度的变化自由切换。

# Nomination on App Store

MadTunes is a premium HiFi music player tailored for audiophiles with extensive FLAC, MP3, and M4A collections. Built on macOS/iOS native AVFoundation and AVPlayer modules, it delivers exceptional sonic fidelity—preserving "depth," "imaging," and "texture" by utilizing Apple’s advanced SRC algorithms without unnecessary signal processing. 

A key highlight is its DSP-agnostic philosophy: MadTunes skips internal effects, instead allowing users to route audio via virtual drivers (like BlackHole) into Apple MainStage, etc. This enables the use of industry-grade VST/AU plugins for a truly bespoke listening experience. MadTunes eliminates rigid library constraints. It indexes files via sandbox bookmarks, allowing your collection to reside across any drive. Its dynamic playlists are driven by hierarchical predicates, while the UI revives intuitive classics: a "foldable-album-grid" desktop experience for macOS & iPadOS and a mobile "pivot-page" design for ensuring seamless navigation on iOS.
