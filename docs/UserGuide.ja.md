# MadTunes ユーザーガイド

## はじめに

MadTunes は、オーディオフィルと音楽制作者向けに設計されたローカル音楽プレーヤーです。クラシックな iTunes 11 スタイルのグリッドレイアウトを採用し、正確で色付けのない高品質なオーディオ再生を提供します。

---

## システム要件

- **macOS**: 15.0 以降
- **iOS/iPadOS**: 18.0 以降

---

## 対応オーディオフォーマット

MadTunes は以下のオーディオフォーマットの再生に対応しています：

| フォーマット | 拡張子 |
|--------------|--------|
| MPEG Audio | `.mp3`, `.mp2` |
| AAC / M4A | `.m4a`, `.aac` |
| Apple Lossless | `.m4a` |
| FLAC | `.flac` |
| WAV | `.wav` |
| AIFF | `.aif`, `.aiff` |
| Ogg Vorbis | `.ogg` |
| Opus | `.opus` |
| Core Audio Format | `.caf` |
| Sound Designer II | `.sd2` |
| Dolby Digital | `.ac3` |

> **注意：** MadTunes はオーディオファイルのみをサポートし、動画形式はサポートしていません。

## インターフェースレイアウト

MadTunes は3カラムのナビゲーションレイアウトを採用しています：

```
┌─────────────────┬─────────────────────────────────────┐
│                 │                                     │
│   サイドバー     │          アルバムグリッド領域         │
│  (Sidebar)      │        (Album Grid View)            │
│                 │                                     │
│ • All Music     │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
│ • Favorites     │  │Album│ │Album│ │Album│ │Album│   │
│ • プレイリスト... │  │Art  │ │Art  │ │Art  │ │Art  │   │
│                 │  └─────┘ └─────┘ └─────┘ └─────┘   │
│                 │       [展開されたアルバムトラックリスト]│
├─────────────────┤                                     │
│                 └─────────────────────────────────────┘
│  プレーヤーコントロール                                    │
│  (Player Controls)                                    │
└───────────────────────────────────────────────────────┘
```

### 1. サイドバー (Sidebar)

サイドバーは左側にあり、以下のセクションで構成されています：

**ライブラリ (Library)**
- **All Music**: ライブラリ内のすべてのトラックを表示
- **Favorites**: お気に入りとしてマークされたトラックを表示（ハートアイコンをクリックして追加）

**プレイリスト (Playlists)**
- ユーザー作成の静的プレイリスト
- 右クリックでプレイリストの作成、名前変更、削除が可能

### 2. アルバムグリッド領域 (Album Grid)

アルバムグリッドはメインの閲覧エリアです：

- **グリッドレイアウト**: カラム数が自動調整され、アルバムあたり最小幅160px
- **アルバムカード**: アルバムアートワーク、アルバムタイトル、アーティスト名を表示
- **展開/折りたたみ**: アルバムをクリックしてトラックリストを展開；もう一度クリックまたは Esc で折りたたみ
- **空白領域クリックで閉じる**: アルバムが展開されているとき、グリッドのカードや詳細ペイン外の空白をクリックしても折りたためます
- **複数選択**: Shift キーと Command キーによる複数選択に対応

**展開されたアルバムビュー** (Expanded Album View)

展開時に表示される内容：
- 左側：複数カラムのトラックリスト（1カラムあたり最大7行）
- 右側：大きなアルバムアートワーク（200×200px）
  - **アートワークをダブルクリック**：アルバムを再生
  - **アートワークを右クリック**：アルバムのコンテキストメニューを表示
- トラック情報：トラック番号、タイトル、アーティスト、再生時間

### 3. プレーヤーコントロール (Player Controls)

ウィンドウ下部に配置され、以下を含みます：

| 要素 | 機能 |
|------|------|
| アルバムアートワークサムネイル | ダブルクリックで現在再生中のアルバムにジャンプ；右クリックでトラック操作メニュー |
| トラックタイトル/アーティスト | 現在の再生情報を表示 |
| 再生/一時停止 | 再生状態を切り替え |
| 前へ/次へ | トラックを切り替え |
| プログレスバー | ドラッグでシーク；時間表示をクリックして残り時間表示を切り替え |
| 音量スライダー | 音量を調整（音量に応じてアイコンが変化）|
| ループモード | 順次 / 1曲リピート / シャッフル |
| 再生キュー | 再生キューパネルを開く |
| カラムブラウザ | Genre/Artist/Album フィルターパネルを開く |

## マウス/トラックパッド操作

### アルバムグリッド

右上ツールバーのボタンで、標準のグリッド表示と表形式（テーブル）表示を切り替えられます。

| 操作 | 機能 |
|------|------|
| アルバムをクリック | アルバムを展開/折りたたみ |
| アルバムをダブルクリック | アルバムの最初のトラックから再生を開始 |
| アルバムを右クリック | コンテキストメニューを表示 |

### トラックリスト

| 操作 | 機能 |
|------|------|
| トラックをクリック | トラックを選択 |
| トラックをダブルクリック | トラックを再生 |
| トラックを右クリック | コンテキストメニューを表示 |

### テーブル表示

テーブル表示では全トラックが一覧として表示され、列は名前・長さ・アーティスト・アルバム名・アルバムアーティスト・ジャンル・フォルダ（親フォルダ名、ホバーでフルパス）を含みます。

#### テーブルのキーボードショートカット

| ショートカット | 機能 |
|----------------|------|
| `↑` `↓` | 選択を上下に移動 |
| `Shift + ↑` `Shift + ↓` | 範囲選択 |
| `Page Up` / `Page Down` | 1 ページ分スクロール |
| `Shift + Page Up/Down` | 前後ページまで範囲選択 |
| `Home` / `End` | 先頭/末尾のトラックへ移動 |
| `Shift + Home/End` | 先頭/末尾のトラックまで範囲選択 |
| `Return` / `Enter` | 選択位置から再生（ダブルクリック同様） |
| `Shift + Space` | 選択位置から再生（ダブルクリック同様） |
| `Space` | 再生 / 一時停止 |
| `⌘ + ↓` | 選択位置から再生（ダブルクリック同様） |
| `⌘ + A` | 表示中の全トラックを選択 |
| `⌘ + C` | 選択トラックのメタデータ（TSV 形式）をクリップボードにコピー |
| `⌥ + ↑` | プレイリスト内で選択トラックを上に移動（お気に入り／静的プレイリストのみ）|
| `⌥ + ↓` | プレイリスト内で選択トラックを下に移動（お気に入り／静的プレイリストのみ）|

#### 列のカスタマイズとソート

- **列の表示切替**: テーブルヘッダーを右クリックすると、トグルメニューで列の表示 / 非表示を切り替えられます。
- **列幅の変更**: 列ヘッダー間の仕切りをドラッグして幅を調整できます。設定はセッション間で保持されます。
- **ソート**: 列ヘッダーをクリックするとその列でソートされます（1回目：昇順 ▲、2回目：降順 ▼、3回目：ソート解除してアルバム順に戻る）

#### プレイリストのトラック並べ替え

お気に入りおよびユーザー作成の静的プレイリスト内で（テーブルのソート・検索・カラムブラウザのフィルターが有効でない場合）、トラックの順序を変更できます：

- **ドラッグ＆ドロップ**: トラック（または複数選択したトラック）を別の行にドラッグして並べ替え。
- **キーボード**: トラックを選択して `⌥ + ↑` / `⌥ + ↓` で上下に移動。

### プレーヤーコントロール

| 操作 | 機能 |
|------|------|
| アルバムアートワークをダブルクリック | メインビューで現在のアルバムを探す |
| 時間表示をクリック | 経過時間 / 残り時間を切り替え |
| プログレスバーをドラッグ | 指定位置にシーク |

## コンテキストメニュー機能

### アルバム右クリックメニュー

- **プレイリストに追加**: アルバムを指定したプレイリストに追加
- **アルバムを再生（順次）**: トラック番号順に再生
- **アルバムを再生（シャッフル）**: ランダム順に再生
- **次に再生**: アルバムを現在の位置の後に挿入してすぐに再生
- **情報を表示**: アルバム内のトラックの詳細情報を表示
- **お気に入りに追加**: アルバム内のすべてのトラックをお気に入りとしてマーク
- **Finder に表示**: アルバムのあるフォルダを Finder で開く
- **ライブラリから削除**: ライブラリから削除（元のファイルは削除されません）

### トラック右クリックメニュー

- **プレイリストに追加**: トラックを指定したプレイリストに追加
- **次に再生**: トラックを現在の位置の後に挿入してすぐに再生
- **情報を表示**: トラックの詳細メタデータを表示
- **お気に入りに追加**: トラックをお気に入りとしてマーク
- **メタデータをコピー**: TSV形式のメタデータをクリップボードにコピー
- **Finder に表示**: トラックのあるフォルダを Finder で開く
- **ライブラリから削除**: ライブラリから削除（元のファイルは削除されません）

## 検索とフィルタリング

### キーワード検索

右上の検索ボックスは以下のフィルターモードをサポートしています：

| モード | 説明 |
|--------|------|
| いずれか | トラックタイトル、アルバムタイトル、アーティストを検索 |
| トラックタイトル | トラックタイトルのみを検索 |
| アルバムタイトル | アルバムタイトルのみを検索 |
| アーティスト | アーティスト名のみを検索 |

### カラムブラウザ (Column Browser)

プレーヤーコントロールのフィルターボタンから開きます：

- **4カラムフィルター**: Genre → Album Artist → Song Artist → Album
- **双方向**：曲アーティストを選択すると、アルバムアーティストの一覧も絞り込まれます。
- **カスケードフィルタリング**: Genre を選択すると、利用可能な Artist リストがフィルタリングされます
- **複数選択**: 各カラムで複数の項目を選択可能
- **ダブルクリックで再生**: 任意のカラムでダブルクリックすると、条件に一致するトラックを再生

## 音楽のインポート

### インポート方法

1. **ファイルインポート**: 複数のオーディオファイルを選択可能
2. **フォルダインポート**: フォルダを再帰的にスキャンしてオーディオファイルを検索
3. **ドラッグ＆ドロップ**: ファイルまたはフォルダを MadTunes ウィンドウにドラッグ
4. **「このアプリで開く」/共有**: Finder やファイルアプリ等から「このアプリで開く」や共有メニューを使ってオーディオファイルを MadTunes に送信

### インポート機能

- **並行処理**: 最大8ファイル同時にメタデータを読み取り
- **重複検出**: 既にインポートされた同じファイルを自動的にスキップ
- **メタデータ読み取り**: ID3タグとアルバムアートワークを自動的に読み取り
- **セキュリティスコープブックマーク**: macOSのセキュリティブックマークを使用してファイルアクセス権限を維持
- **プレイリスト同期**: 「Favorites」ページや任意の静的プレイリストを表示中にインポートすると、そのプレイリストにも自動的にトラックが追加されます（重複は無視されます）

## オーディオ機能

### 高品質再生

MadTunes は macOS オーディオシステム向けに特別に最適化されています：

- **システムレベル AVPlayer コア**: 100回以上の厳密なテストを経て検証済み、macOS プラットフォームではシステムネイティブの AVPlayer を使用することのみが最高の音質を保証します。テストアルバムには加藤達也（「食戟のソーマ」OST）、梁静茹（「勇気」「可惜不是你」）、FLOW（「Go!!!」「Sign」）、ずっと真夜中でいいのに（「勘ぐれい」）、方順吉（張翊華ミックス作品）、√5（「千本桜」）、周杰倫（「軌跡」）などが含まれ、あらゆるジャンルの音楽のディテールを正確に再現することを確認済み
- **HAL バッファ調整**: 出力デバイスのバッファを自動的に増やし、オーディオジッターを防止
- **正確なステレオ**: HRTF処理なしで、元のミックスを忠実に再現
- **シームレスループ**: 1曲リピートモードで、トラックの終わりと始まりの間にシームレスな移行

### メタデータ表示

「情報を表示」ウィンドウで以下が表示できます：

- 基本情報：タイトル、アーティスト、アルバム、年、ジャンル
- 技術情報：サンプリングレート、ビット深度、チャンネル数、コーデック
- ファイル情報：ファイルパス、ファイルサイズ、変更日

## データ管理

### ライブラリストレージ

MadTunes は SwiftData を使用して永続的にデータを保存します：

- トラックメタデータ（元のオーディオファイルではありません）
- プレイリスト
- お気に入りマーク
- ファイルセキュリティブックマーク（macOS）

### 注意事項

- ライブラリからトラックを削除しても、元のオーディオファイルは**削除されません**
- アルバムアートワークは自動的に圧縮されキャッシュされます（最大512×512、JPEG形式）
- 既存のファイルを再インポートすると、そのメタデータが更新されます

## インタラクションスタイルの概要

MadTunes は以下の設計原則に従います：

1. **直接操作**: ダブルクリックで再生、ドラッグで並べ替え、即時フィードバック
2. **キーボード優先**: 包括的なキーボードナビゲーションサポート、マウスなしでほとんどの操作が可能
3. **段階的開示**: グリッド → アルバム → トラック、明確な情報階層
4. **非破壊的編集**: すべての削除操作はライブラリインデックスにのみ影響し、元のファイルは安全
5. **macOS ネイティブ**: Apple Human Interface Guidelines に従い、Spotlight、Force Touch などのシステム機能をサポート

## トラブルシューティング

### よくある問題

| 問題 | 解決策 |
|------|--------|
| ファイルを再生できない | ファイルが元の場所にあるか確認；再インポートを試みる |
| インポートが遅い | 大量のファイルでは正常な現象；バックグラウンドインポートをサポート |
| アルバムアートワークが表示されない | オーディオファイルに埋め込まれたアートワークがあるか確認；FLAC/MP3/M4Aのアートワーク読み取りをサポート |
| 再生時にスキップする | システムオーディオ設定を確認；他のオーディオ使用アプリを閉じる |

### サポートへの連絡

問題や提案がある場合は、App Store ページまたは GitHub リポジトリからフィードバックを送信してください。
