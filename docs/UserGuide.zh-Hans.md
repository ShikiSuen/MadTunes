# MadTunes 使用说明

## 简介

MadTunes 是一款面向 Audiophile 和音乐制作人的本地音乐播放器，采用经典的 iTunes 11 风格网格布局，提供精准、无染色的音频回放体验。

---

## 系统要求

- **macOS**: 15.0 或更高版本
- **iOS/iPadOS**: 18.0 或更高版本

---

## 支持的音频格式

MadTunes 支持以下音频格式的播放：

| 格式 | 扩展名 |
|------|--------|
| MPEG Audio | `.mp3`, `.mp2` |
| AAC / M4A | `.m4a`, `.aac` |
| Apple Lossless | `.m4a` |
| FLAC | `.flac` |
| WAV | `.wav` |
| AIFF | `.aif`, `.aiff` |
| Ogg Vorbis | `.ogg` |
| Opus | `.opus` |
| Core Audio Format | `.caf` |
| Sound Designer II | `.sd2` |
| Dolby Digital | `.ac3` |

> **注意：** MadTunes 仅支持音频文件，不支持视频格式。

## 界面布局

MadTunes 采用三栏式导航布局：

```
┌─────────────────┬─────────────────────────────────────┐
│                 │                                     │
│   侧边栏         │          专辑网格区域                │
│  (Sidebar)      │        (Album Grid View)            │
│                 │                                     │
│ • All Music     │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
│ • Favorites     │  │专辑 │ │专辑 │ │专辑 │ │专辑 │   │
│ • 播放列表...    │  │封面 │ │封面 │ │封面 │ │封面 │   │
│                 │  └─────┘ └─────┘ └─────┘ └─────┘   │
│                 │       [展开的专辑曲目列表]            │
├─────────────────┤                                     │
│                 └─────────────────────────────────────┘
│  播放控制条                                                │
│  (Player Controls)                                    │
└───────────────────────────────────────────────────────┘
```

### 1. 侧边栏 (Sidebar)

侧边栏位于左侧，包含以下部分：

**资料库 (Library)**
- **All Music**: 显示媒体柜中的所有曲目
- **Favorites**: 显示标记为喜好的曲目（点击心形图标添加）

**播放列表 (Playlists)**
- 用户创建的静态播放列表
- 右键点击可新建、重命名或删除播放列表

### 2. 专辑网格区域 (Album Grid)
右上角工具栏有个按钮，可以在标准网格布局和列表式表格视图之间切换。
专辑网格是主浏览区域：

- **网格布局**: 自适应列数，最少 160px 宽度每张专辑
- **专辑卡片**: 显示专辑封面、专辑名称、艺人名称
- **展开/折叠**: 单击专辑展开曲目列表；再次单击或按 Esc 折叠
- **点击空白区域关闭**: 当专辑展开时，点击网格中专辑卡片和详情窗外的任何空白处也会收起它
- **多选**: 支持 Shift 和 Command 键多选专辑

**展开的专辑视图** (Expanded Album View)

展开后显示：
- 左侧：多列曲目列表（最多 7 行每列）
- 右侧：大尺寸专辑封面（200×200px）
  - **双击封面**：播放该专辑
  - **右键封面**：显示专辑上下文菜单
- 曲目信息：音轨编号、曲名、艺人、时长

### 3. 播放控制条 (Player Controls)

位于窗口底部，包含：

| 元素 | 功能 |
|------|------|
| 专辑封面缩略图 | 双击跳转到当前播放专辑；右键显示曲目操作菜单 |
| 曲名/艺人 | 显示当前播放信息 |
| 播放/暂停 | 切换播放状态 |
| 上一首/下一首 | 切换曲目 |
| 进度条 | 拖动跳转；点击时间切换剩余时间显示 |
| 音量滑块 | 调节音量（图标随音量变化）|
| 循环模式 | 顺序 / 单曲循环 / 乱序 |
| 播放队列 | 弹出播放队列面板 |
| 直栏浏览器 | 弹出 Genre/Artist/Album 筛选面板 |

## 键盘热键

### 全局热键

| 热键 | 功能 |
|------|------|
| `Space` | 展开专辑（折叠时）/ 播放/暂停（展开时） |
| `Shift + Space` | 播放/暂停（折叠时）/ 播放所选或收起（展开时） |

### 专辑网格导航

当没有专辑展开时：

| 热键 | 功能 |
|------|------|
| `←` `→` `↑` `↓` | 在专辑网格中移动选择 |
| `Shift + 方向键` | 范围选择多个专辑 |
| `Page Up` / `Page Down` | 向上/向下翻页 |
| `Shift + Page Up/Down` | 范围选择到上一页/下一页 |
| `Home` / `End` | 跳转到首个/末个专辑 |
| `Shift + Home/End` | 范围选择至首个/末个专辑 |
| `Return` / `Enter` | 展开/折叠选中的专辑 |
| `⌘ + ↓` | 展开选中的专辑 |
| `⌘ + A` | 选中所有肉眼可见的专辑（受 Column Browser 与搜索筛选影响）|

| 热键 | 功能 |
|------|------|
| `⌘ + 单击` | 多选/取消选择专辑 |
| `Shift + 单击` | 从锚点到点击位置范围选择 |
| `拖拽选择` | 橡皮筋框选多个专辑（按住 ⌘ 追加选择）|

### 展开的专辑内导航

当专辑展开时：

| 热键 | 功能 |
|------|------|
| `↑` `↓` | 在曲目列表中移动选择 |
| `←` `→` | 在曲目列之间跳转 |
| `Return` / `Enter` | 播放选中的曲目 |
| `Esc` / `⌘ + ↑` | 折叠专辑，返回网格视图 |
| `Space` | 播放/暂停 |
| `Shift + Space` | 播放所选曲目、或收起专辑 |
| `⌘ + A` | 选中当前专辑下所有肉眼可见的曲目（受搜索筛选影响）|
| `⌘ + C` | 复制选中曲目的中继资料（TSV 格式）到剪贴簿 |

| 热键 | 功能 |
|------|------|
| `⌘ + 单击` | 多选/取消选择曲目 |
| `Shift + 单击` | 范围选择曲目 |
| `Shift + 拖拽` | 拖拽选择多个曲目 |

### 播放队列热键

在播放队列面板中：

| 热键 | 功能 |
|------|------|
| `↑` `↓` | 在队列中移动选择 |
| `Delete` / `⌫` | 移除选中的曲目 |
| `Return` / `Enter` | 跳转到选中的曲目并播放 |

## 鼠标/触控板操作

### 专辑网格

| 操作 | 功能 |
|------|------|
| 单击专辑 | 展开/折叠专辑 |
| 双击专辑 | 从该专辑第一首开始播放 |
| 右键专辑 | 显示上下文菜单 |

### 曲目列表

| 操作 | 功能 |
|------|------|
| 单击曲目 | 选中该曲目 |
| 双击曲目 | 播放该曲目 |
| 右键曲目 | 显示上下文菜单 |

### 表格视图

表格视图显示所有曲目列表，列包括名称、时长、艺人、专辑名称、专辑艺人、风格
以及文件夹（父文件夹名称，鼠标悬停显示完整路径）。

#### 表格视图键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `↑` `↓` | 上下移动选择 |
| `Shift + ↑` `Shift + ↓` | 范围选择 |
| `Page Up` / `Page Down` | 上下翻页 |
| `Shift + Page Up/Down` | 范围选择至上一页/下一页 |
| `Home` / `End` | 跳转到首个/末个曲目 |
| `Shift + Home/End` | 范围选择至首个/末个曲目 |
| `Return` / `Enter` | 从所选位置播放（同双击） |
| `Shift + Space` | 从所选位置播放（同双击） |
| `Space` | 播放/暂停 |
| `⌘ + ↓` | 从所选位置播放（同双击） |
| `⌘ + A` | 全选可见曲目 |
| `⌘ + C` | 将所选曲目的中继资料（TSV 格式）拷贝至剪贴板 |
| `⌥ + ↑` | 在播放清单中上移所选曲目（仅限收藏 / 静态播放清单）|
| `⌥ + ↓` | 在播放清单中下移所选曲目（仅限收藏 / 静态播放清单）|

#### 栏位自定与排序

- **栏位显示**: 右键点击表头可通过开关菜单来显示或隐藏栏位。
- **调整栏宽**: 拖曳栏位标头之间的分隔线可调整栏宽，宽度设定会跨工作阶段保留。
- **排序**: 点击栏位标题可依该栏位排序（点击一次升序 ▲、再次点击降序 ▼、第三次点击清除排序恢复专辑顺序）

#### 播放清单曲目重排序

在收藏和用户创建的静态播放清单中（当表格未排序、未搜索、未启用栏位筛选时），可以重新排列曲目：

- **拖拽排序**: 拖动曲目（或多选的曲目）到另一行以重新排序。
- **键盘排序**: 选中曲目后按 `⌥ + ↑` / `⌥ + ↓` 上下移动。

| 操作 | 功能 |

## 上下文菜单功能

### 专辑右键菜单

- **加入到播放清单**: 将专辑添加到指定播放列表
- **播放该专辑（顺序）**: 按曲目编号顺序播放
- **播放该专辑（乱序）**: 随机顺序播放
- **插播**: 将专辑插入当前播放位置之后立即播放
- **取得资讯**: 查看专辑中曲目的详细信息
- **加入喜好项目**: 将专辑所有曲目标记为喜好
- **显示于档案总管**: 在 Finder 中打开专辑所在文件夹
- **从数据库删除登记**: 从媒体柜中移除（不删除原始文件）

### 曲目右键菜单

- **加入到播放清单**: 将曲目添加到指定播放列表
- **插播**: 将曲目插入当前播放位置之后立即播放
- **取得资讯**: 查看曲目的详细元数据
- **加入喜好项目**: 将曲目标记为喜好
- **拷贝中继资料**: 复制 TSV 格式的元数据到剪贴板
- **显示于档案总管**: 在 Finder 中打开曲目所在文件夹
- **从数据库删除登记**: 从媒体柜中移除（不删除原始文件）

## 搜索与筛选

### 关键字搜索

右上角搜索框支持以下过滤模式：

| 模式 | 说明 |
|------|------|
| 任一 | 搜索曲目名称、专辑名称、艺人 |
| 曲目名称 | 仅搜索曲目名称 |
| 专辑名称 | 仅搜索专辑名称 |
| 艺人 | 仅搜索艺人名称 |

### 直栏浏览器 (Column Browser)

通过播放控制条的筛选按钮打开：

- **四栏筛选**: Genre → Album Artist → Song Artist → Album
- **双向限制**：选择歌曲艺人时也会限制专辑艺人列表。
- **级联过滤**: 选择 Genre 后会过滤可用的 Artist 列表
- **多选**: 每栏支持选择多个项目
- **双击播放**: 在任意栏中双击可播放符合条件的曲目

## 播放队列管理

### 队列操作

播放队列面板中可执行：

- **拖拽排序**: 拖动曲目调整播放顺序

- **随机打乱**: 点击顶部乱序按钮
- **上下移动**: 使用箭头按钮微调位置

### 循环模式

| 模式 | 图标 | 说明 |
|------|------|------|
| 顺序播放 | ⟳ | 按顺序播放，结束后停止 |
| 单曲循环 | ⟳1 | 重复播放当前曲目（首尾无缝衔接）|
| 乱序播放 | ⇄ | 随机顺序播放队列中的曲目 |

## 导入音乐

### 导入方式

1. **文件导入**: 支持选择多个音频文件
2. **文件夹导入**: 递归扫描文件夹中的所有音频文件
3. **拖拽导入**: 将文件或文件夹拖入 MadTunes 窗口
4. **「用此 App 打开」/ 共享**: 通过 Finder、「文件」App 或其他应用的「用此 App 打开」或共享菜单将音频文件发送给 MadTunes

### 导入特性

- **并行处理**: 最多 8 个文件同时读取元数据
- **重复检测**: 自动跳过已导入的相同文件
- **元数据读取**: 自动读取 ID3 标签和专辑封面
- **安全范围书签**: macOS 下使用安全书签保持文件访问权限
- **播放列表同步**: 若在“Favorites”页面或任意自定义静态播放列表页执行导入，导入完成后这些曲目也会自动加入到该列表中（已存在的曲目将被跳过）

## 音频特性

### 高品质回放

MadTunes 针对 macOS 音频系统进行了专门优化：

- **系统级 AVPlayer 核心**: 经过上百次实测验证，macOS 平台唯有使用系统原生 AVPlayer 才能确保最佳音质表现。测试专辑涵盖加藤达也《食戟之灵 OST》、梁静茹《勇气》《可惜不是你》、FLOW《Go!!!》《Sign》、ずっと真夜中でいいのに《勘ぐれい》、方顺吉（张翊华混音作品）、√5《千本樱》、周杰伦《轨迹》等，确认各类型音乐的细节都能精准呈现
- **HAL 缓冲区调整**: 自动增大输出设备缓冲区，防止音频抖动
- **精确立体声**: 无 HRTF 处理，忠实还原原始混音
- **无缝循环**: 单曲循环模式下，曲目首尾衔接无停顿

### 元数据显示

在「取得资讯」窗口中可查看：

- 基础信息：曲名、艺人、专辑、年份、风格
- 技术信息：采样率、位深度、声道数、编码格式
- 文件信息：文件路径、文件大小、修改日期

## 数据管理

### 媒体柜存储

MadTunes 使用 SwiftData 持久化存储：

- 曲目元数据（非原始音频文件）
- 播放列表
- 喜好标记
- 文件安全书签（macOS）

### 注意事项

- 从媒体柜删除曲目**不会**删除原始音频文件
- 专辑封面自动压缩缓存（最大 512×512，JPEG 格式）
- 重新导入已存在的文件会更新其元数据

## 交互风格总结

MadTunes 的交互设计遵循以下原则：

1. **直接操作**: 双击播放、拖拽排序、即时反馈
2. **键盘优先**: 全面的键盘导航支持，无需鼠标即可完成大部分操作
3. **渐进展开**: 网格 → 专辑 → 曲目，信息层级清晰
4. **无损编辑**: 所有删除操作仅影响媒体柜索引，原始文件安全
5. **macOS 原生**: 遵循 Apple Human Interface Guidelines，支持系统特性如 Spotlight、Force Touch 等

## 故障排除

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 无法播放文件 | 检查文件是否在原位置；尝试重新导入 |
| 导入速度慢 | 大量文件时属于正常现象；支持后台导入 |
| 专辑封面不显示 | 检查音频文件是否内嵌封面；支持 FLAC/MP3/M4A 封面读取 |
| 播放时有卡顿 | 检查系统音频设置；关闭其他占用音频的应用 |
